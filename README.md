# AutoM - Premium Marketplace Mockup

A modern, multi-page React application built with Vite featuring a premium silver-themed marketplace design.

## 🌟 Features

- **Multi-Language Support**: Complete translations in English, Russian, and Estonian
- **Modern UI Effects**: Glassmorphism, animated gradients, parallax, and scroll reveal animations
- **Responsive Design**: Mobile-friendly layouts for all screen sizes
- **React Router Navigation**: Seamless multi-page experience
- **Silver Branding**: Premium silver color scheme throughout
- **Space Grotesk Font**: Modern, clean typography

## 📄 Pages

1. **Home** - Hero section with animated gradients and parallax effects
2. **Browse Listings** - Product grid with filters and sorting options
3. **Post Ad** - Multi-step form with mock payment flow (3 steps)
4. **Pricing** - Three-tier pricing plans
5. **FAQ** - Accordion-style questions and answers
6. **Contact** - Contact form and information

## 🚀 Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

The application will be available at `http://localhost:5173/`

### Build

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## 🎨 Design Features

- **Glassmorphism Effects**: Frosted glass appearance with backdrop blur
- **Animated Gradients**: Smooth color transitions on hero sections
- **Parallax Scrolling**: Depth effect on home page hero
- **Scroll Reveal Animations**: Elements fade in as you scroll
- **Hover Effects**: Subtle motion on interactive elements
- **Silver Theme**: Consistent use of #c0c0c0, #a8a8a8, #e8e8e8

## 🌍 Language Toggle

Switch between English (EN), Russian (RU), and Estonian (ET) using the language toggle in the header.

## ⚠️ Important Note

This is a **frontend-only mockup**. The payment processing in the "Post Ad" flow is visual only and does not handle real transactions.

## 📦 Technologies Used

- React 19
- Vite 7
- React Router DOM 6
